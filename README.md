# آکادمی پرستیژ | Prestige Gemology

وب‌اپلیکیشن آموزشی فارسی و راست‌به‌چپ، بر پایه طرح HTML ارسالی و لوگوی اصلی برند.

## اجرای سریع در ویندوز

فایل `Start-Prestige.cmd` را دوبار کلیک کنید و پنجره آن را باز نگه دارید. سپس آدرس `http://127.0.0.1:3000` را در مرورگر باز کنید. روی این لپ‌تاپ، برنامه از Node.js همراه GapGPT نیز استفاده می‌کند.

روی دستگاه دیگر، Node.js نسخه ۲۴ یا جدیدتر لازم است. هیچ بسته اضافی نیاز نیست:

```sh
node server.mjs
```

برای آزمایش:

```sh
node --test tests/*.test.mjs
```

## امکانات فعال

- ثبت‌نام، ورود و خروج واقعی؛ رمزها با scrypt و salt ذخیره می‌شوند.
- نشست هفت‌روزه با کوکی HttpOnly؛ بدون نگهداری رمز یا توکن در localStorage.
- فهرست دوره، جست‌وجو و فیلتر سطح، صفحه جزئیات و ۱۲ درس متنی نمونه.
- ثبت‌نام رایگان دوره نمونه و ذخیره پایدار پیشرفت هر دانشجو.
- داشبورد اختصاصی با جداسازی داده‌های حساب‌ها.
- ثبت درخواست اشتراک بدون پرداخت یا فعال‌سازی ساختگی.
- تیکت پشتیبانی، مشاهده پاسخ در داشبورد و پاسخ‌گویی مدیر.
- پایگاه داده SQLite، اعتبارسنجی سرور، کنترل مبدأ درخواست و محدودیت تلاش ورود.
- نمایش واکنش‌گرا برای موبایل و دسکتاپ و استفاده از لوگوی ارسالی.

## مدیریت پشتیبانی

در PowerShell، ایمیل حساب مدیر را قبل از شروع سرور تنظیم کنید. سپس همان ایمیل را در برنامه ثبت‌نام کنید و وارد شوید:

```powershell
$env:ADMIN_EMAIL = 'your-email@example.com'
node server.mjs
```

بخش مدیریت تیکت‌ها در داشبورد همان حساب ظاهر می‌شود. پیش از انتشار عمومی، حساب مدیر را خودتان بسازید؛ تأیید مالکیت ایمیل و بازیابی رمز هنوز پیاده‌سازی نشده‌اند.

## فایل‌ها و نگهداری داده

- `server.mjs`: سرور و API؛ `catalog.json`: دوره‌ها، پلن‌ها و متن درس‌های نمونه.
- `public/`: رابط فارسی، سبک‌ها و لوگو.
- `data/prestige.sqlite`: اطلاعات حساب‌ها، نشست‌ها، ثبت‌نام‌ها، پیشرفت و درخواست‌ها؛ خودکار ساخته می‌شود و در Git ثبت نمی‌شود.
- برای پشتیبان‌گیری، سرور را متوقف و پوشه `data` را کپی کنید.

## استقرار

این برنامه به میزبان Node.js و فضای ذخیره‌سازی پایدار نیاز دارد. GitHub محل نگهداری کد است؛ GitHub Pages بک‌اند و SQLite این برنامه را اجرا نمی‌کند.

متغیرهای محیطی اختیاری:

| نام | کاربرد |
| --- | --- |
| `PORT` | پورت؛ پیش‌فرض 3000 |
| `HOST` | پیش‌فرض 127.0.0.1؛ برای میزبانی 0.0.0.0 |
| `DB_PATH` | مسیر فایل پایگاه داده |
| `ADMIN_EMAIL` | ایمیل حساب مدیر |
| `COOKIE_SECURE` | روی HTTPS مقدار true |
| `PUBLIC_ORIGIN` | آدرس عمومی کامل سایت در صورت استفاده از reverse proxy |

Docker اختیاری:

```sh
docker build -t prestige-gemology .
docker run --name prestige -p 3000:3000 -v prestige-data:/app/data prestige-gemology
```

برای انتشار عمومی از HTTPS، حجم پایدار پایگاه داده و پشتیبان‌گیری استفاده کنید. SQLite داخلی Node.js 24 ممکن است هشدار Experimental نشان دهد.

## وضعیت محتوا و سرویس‌ها

فایل اولیه یک نمونه نمایشی بود. این نسخه، ورود و ذخیره اطلاعات واقعی را به آن اضافه می‌کند. متن ۱۲ درس، محتوای نمونه است و باید با محتوای نهایی و بازبینی‌شده مدرس جایگزین شود. ویدئو، آزمون رسمی، گواهی حرفه‌ای، ایمیل خودکار، پیام‌رسان، پرداخت و فعال‌سازی اشتراک متصل نیستند. قیمت‌ها و امکانات پلن‌ها از طرح اولیه حفظ شده‌اند و پیشنهاد نسخه نهایی محسوب می‌شوند. اطلاعات تماس طرح اولیه پیش از انتشار باید توسط صاحب برند تأیید شود.
